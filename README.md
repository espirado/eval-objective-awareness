# Evaluation-objective awareness

A separate experiment from compliance labeling. The intervention to replicate, on tasks this repo controls, is:

- Say only that the interaction is an evaluation.
- Name the correct objective.
- Name the opposite objective.

The published frontier result is that the bare word "evaluation" does not move success, and naming the objective does, in opposite directions. An open-weight replication belongs here. A null result is a result. Do not mix these runs into the partial-compliance corpus.
